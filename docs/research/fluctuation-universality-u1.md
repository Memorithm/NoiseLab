# Fluctuation universality — Stage U1 panel

## Status

This document freezes the first executable panel before its outcomes are interpreted. It follows Stage U0 in `fluctuation-universality.md` and does not alter the Stage U0 statistic after observing data.

Stage U1 is still calibration/exploration. It cannot establish a universal law or common cosmological origin.

## Objective

Exercise the multiscale/surrogate machinery on a small panel that contains:

1. a same-family IID control;
2. a same-mechanism correlated family with changed correlation time;
3. an IID-versus-correlated temporal-structure control;
4. a cross-mechanism stochastic/dynamical comparison.

The purpose is to learn whether the declared descriptor and shuffled-null gate behave sensibly before adding external physical datasets or protected confirmatory families.

## Sources

All stochastic draws are deterministic under explicit seeds and reuse pinned SciRust primitives where available.

### Gaussian white A and B

Two independent zero-mean unit-scale Gaussian white-noise realizations generated through NoiseLab's SciRust bridge.

Purpose: same-family IID control. Because they may already be close at the finest scale, the panel retains absolute fine and terminal distances instead of requiring a positive convergence score.

### Ornstein-Uhlenbeck fast and slow

Two stationary-variance-matched OU processes:

```text
fast: theta = 2.0
slow: theta = 0.25
mu = 0
dt = 0.05
sigma = sqrt(2 theta)
```

For `dX = theta(mu-X)dt + sigma dW`, this choice gives unit stationary variance in the continuous-time model. The raw series is still standardized by the universality harness.

Purpose: same stochastic mechanism with substantially different correlation time.

### Double-well Langevin

Unforced symmetric quartic double well:

```text
a = 1
b = 1
forcing amplitude = 0
noise intensity D = 0.25
dt = 0.01
initial state = +sqrt(a/b)
```

The trajectory is generated by the existing NoiseLab Euler-Maruyama calibration code using SciRust `SplitMix64` for stochastic draws.

Purpose: exploratory cross-mechanism comparison with the slow OU process.

## Default sample protocol

```text
retained samples = 8192
burn-in samples = 1024
coarse scales = 1, 2, 4, 8, 16
surrogates = 199
alpha = 0.05
```

The CI regression uses a smaller deterministic configuration only to keep validation bounded. Scientific runs should use the default or a separately preregistered larger configuration.

## Fixed pair list

The executable pair order is:

1. `GaussianWhiteA` vs `GaussianWhiteB` — `WithinIidControl`;
2. `OrnsteinUhlenbeckFast` vs `OrnsteinUhlenbeckSlow` — `WithinOuFamily`;
3. `GaussianWhiteA` vs `OrnsteinUhlenbeckSlow` — `DistinctTemporalControl`;
4. `OrnsteinUhlenbeckSlow` vs `DoubleWellLangevin` — `CrossMechanismExploratory`.

No pair may be dropped after seeing an inconvenient outcome. Additional pairs belong in a new protocol revision.

## Retained outputs

Each comparison keeps:

- fine-scale descriptor distance;
- terminal/coarsest-scale descriptor distance;
- first-to-last convergence score;
- variance-scaling-exponent gap;
- empirical shuffled-surrogate p-value;
- conservative evidence label from Stage U0.

There is intentionally **no aggregate `universal = true/false` field**.

An already-close within-family pair can have little positive convergence because there is little distance to remove. Conversely, a large positive convergence score does not establish common physics if the terminal distance remains large. Both quantities must therefore be inspected.

## Interpretation rules

- `WithinIidControl` calibrates baseline finite-sample descriptor variability; it is not expected to prove anything by converging further.
- `WithinOuFamily` tests sensitivity to correlation-time changes inside a known mechanism.
- `DistinctTemporalControl` checks whether IID and correlated dynamics are spuriously collapsed by the descriptor.
- `CrossMechanismExploratory` is the first direct probe of the conjecture in this panel. Any `SurrogateSeparatedCandidate` remains exploratory and must survive stronger surrogates and independent systems.

No individual p-value is a discovery claim. Stage U1 contains multiple comparisons and no multiplicity-adjusted confirmatory family has yet been declared.

## Exit criteria for Stage U1

Advance toward Stage U2 only when:

1. the panel is deterministic under fixed seeds;
2. all comparisons produce finite retained metrics;
3. the IID control does not expose numerical instability in the descriptor;
4. the distinct-temporal control demonstrates that the pipeline is not trivially collapsing all processes;
5. results are recorded whether positive, null or contrary to expectation.

Stage U2 should then add observables from additional NoiseLab mechanisms with extraction rules frozen before pairwise comparison, followed by spectrum/phase-matched surrogate controls before stronger interpretation.
